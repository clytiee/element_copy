## 中文隐私政策
# 隐私政策 - Element Copy 元素复制
更新日期：2026

Element Copy（下称「本扩展」）高度重视用户隐私保护。

### 数据存储
本扩展仅在**本地浏览器**存储您选择的复制模式（富文本 / 纯文本），该数据**不会上传到任何服务器**，仅在您当前浏览器内生效。所有网页拾取、复制操作全部在本地完成，不会发送网页内容、浏览记录到外部网络。

### 我们不会收集
- 个人身份信息（姓名、邮箱、手机号等）
- 浏览历史、访问网站记录
- 复制的网页文本、图片、网页内容
- IP地址、位置信息

### 第三方共享
本扩展**不会向任何第三方分享、出售、转让您的任何数据**。

### 权限说明
扩展需要网页读取权限，目的仅为拾取页面DOM元素实现复制功能，不会用于其他用途。

### 联系我们
如对本隐私政策有疑问，可通过GitHub项目页面联系开发者。

## English Privacy Policy
# Privacy Policy - Element Copy
Last updated: 2026

Element Copy (hereinafter referred to as "the Extension") respects and protects your privacy.

### Data Storage
The Extension only saves your preferred copy mode (rich text / plain text) **locally within your browser**. This setting will NOT be uploaded to any remote server and only exists locally. All element picking and copy operations run entirely locally. No webpage content or browsing data will be transmitted to external servers.

### Data We Do NOT Collect
- Personal identifiable information (name, email, phone number, etc.)
- Browsing history or visited websites
- Copied web content including texts and images
- IP address or geographic location

### Third-Party Sharing
We will never share, sell, or transfer your data to any third parties.

### Permission Statement
The web access permission required by this extension is solely for picking DOM elements to realize copy function, and will not be used for any other purposes.

### Contact
If you have any questions about this privacy policy, please contact the developer via the GitHub project page.
