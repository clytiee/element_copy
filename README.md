# Element Copy 元素复制
Chrome / Edge Manifest V3 浏览器扩展

## ✨ 功能
拾取页面任意DOM元素，一键复制，支持多种工作模式：
- **富文本模式（默认）**：复制HTML，文字+图片一并保存，粘贴到 Notion / 飞书文档 / Word 可保留图文结构（图片为原链接，断网图片失效）
- **纯文本模式**：仅提取元素内文字
- **连续复制模式**：开启后复制完成不会退出拾取，可连续点击多个元素批量复制；按 `Esc` 退出拾取

## 📌 使用方式
1. **左键点击插件图标**：开启拾取模式
2. 鼠标悬浮页面元素，蓝色框高亮预览目标
3. 点击目标元素执行复制
   - 默认单次模式：复制完成自动退出拾取
   - **连续复制开启时**：保持拾取状态，可以继续点击其他元素复制
4. `Esc` 按键：随时退出拾取模式（两种模式均生效）
5. **右键点击插件图标**：
   - 切换「富文本模式 / 纯文本模式」
   - 开关「连续复制」
   - 所有设置自动持久保存

## 📦 本地安装
1. 下载源码
2. 浏览器地址栏打开 `chrome://extensions/`（Edge：`edge://extensions/`）
3. 开启【开发者模式】
4. 点击【加载已解压的扩展程序】，选中项目文件夹
